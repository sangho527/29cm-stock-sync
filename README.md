# 29CM 재고 동기화 자동화

셀메이트 재고현황의 옵션별 재고를 29커넥트(29CM 파트너센터) 상품의 **옵션/재고 설정**에 자동으로 채워 넣는 파이썬 스크립트입니다.
입력만 자동으로 하고 **수정완료는 사람이 눈으로 확인한 뒤 직접 누르는** 반자동 방식입니다.

## 동작 흐름

엑셀 `29CM_상품관리` 시트의 B열(상품명)을 위에서부터 한 행씩 처리합니다.

1. B열 상품명 읽기 — **색이 칠해진 행(완료·보류)은 건너뜀**
2. 셀메이트 재고현황에서 상품명 검색
   - 검색 필터 `기준`에 **9개 창고가 선택**(`9 selected`)돼 있는지 확인, 아니면 일시정지하고 안내
   - `등급` 오른쪽 `재고` 열 수량을 옵션(컬러·사이즈)별로 합산
3. 29커넥트 상품관리에서 같은 상품명 검색
4. 판매상태가 **판매중**인 상품의 상품번호 클릭 → 새 창에서 `옵션/재고 설정`으로 이동
5. `옵션/재고 설정` 섹션이 접혀 있으면 펼친 뒤(이미 펼쳐져 있으면 그대로), 29CM 옵션명과 셀메이트 옵션을 매칭해 변환된 재고 입력
   - **옵션/재고 설정 섹션 안의 재고 칸만 입력**하고, 가격·판매설정·배송정보·이미지 등 다른 정보는 건드리지 않음
   - 입력 전후로 섹션 밖 모든 입력값을 비교해, 하나라도 바뀌면 결과 창에 경고 표시
   - 파란 테두리 = 입력함, 빨간 테두리 = 매칭 실패(입력 안 함)
6. **일시정지** — 결과 창이 뜨면 확인 후 브라우저에서 `수정완료`를 직접 누르고 `[계속하기]` 클릭
7. 해당 행 B열을 초록색으로 칠하고 다음 행 진행

같은 이름으로 판매중 상품이 여러 개면 하나씩 차례로 처리합니다. 결과 창에는 `[건너뛰기]`, `[중지]` 버튼도 있습니다.

## 재고 변환 규칙

| 셀메이트 재고 | 29CM 입력 |
|---|---|
| 100개 이상 | 100 |
| 50 ~ 99 | 10을 뺀 뒤 일의 자리 버림 (예: 70 → 60, 55 → 40, 99 → 80) |
| 20 ~ 49 | 일의 자리 버림 (예: 37 → 30) |
| 12 ~ 19 | 일의 자리 버림 (→ 10) |
| 6 ~ 11 | 70% 후 버림 (예: 11 → 7, 10 → 7, 6 → 4) |
| 0 ~ 5 | 그대로 |

규칙은 `stock_sync.py` 상단의 `convert_stock()` 함수 숫자만 바꾸면 변경됩니다.

## 설치 (처음 한 번)

### 1. 파이썬 설치

1. [python.org/downloads/windows](https://www.python.org/downloads/windows/)에서 **Python 3.13.x**의 **Windows installer (64-bit)** 를 받습니다. 파일명이 `python-3.13.x-amd64.exe`처럼 **.exe**로 끝나야 합니다.
2. 실행 후 첫 화면 아래 **"Add python.exe to PATH" 체크** → **Install Now**
3. 새 명령 프롬프트에서 `python --version` → `Python 3.13.x`가 나오면 성공

> **"앱 패키지를 열 수 없음 / 앱 패키지를 구문 분석하는 동안 오류가 발생했습니다"** 가 뜨는 경우
> python.org 첫 화면의 새 설치 프로그램(.msix, Python install manager)이 일부 Windows에서 열리지 않아 생기는 오류입니다.
> 위처럼 **.exe 설치 파일**을 받거나, 명령 프롬프트에서 `winget install Python.Python.3.13` 으로 설치하세요.

### 2. 패키지 설치

```
설치.bat 실행
python -m playwright install chromium
```

## 실행 방법 (매번)

1. `크롬_자동화모드.bat`로 크롬 열기
   - 평소 크롬과 분리된 프로필이라 **처음 한 번은 셀메이트·29커넥트 로그인** 필요 (이후 유지됨)
2. 크롬에 탭 두 개 열어두기
   - 셀메이트 **재고현황 목록** (기준 필터 `9 selected` 확인)
   - 29커넥트 **상품관리** (`partner-item.29cm.co.kr/list`)
3. 엑셀에서 `29CM_상품관리` 파일 열어두기
4. 명령 프롬프트에서 실행

```
python stock_sync.py              # 2행부터
python stock_sync.py --start 16   # 16행부터
```

## 설정값

`stock_sync.py` 상단 `설정` 영역에서 바꿀 수 있습니다.

| 항목 | 기본값 | 설명 |
|---|---|---|
| `EXCEL_BOOK` | `29CM_상품관리` | 열려 있는 엑셀 파일 이름(일부) |
| `EXCEL_SHEET` | `None` | 시트 이름, `None`이면 현재 보고 있는 시트 |
| `NAME_COL` | `B` | 상품명 열 |
| `WAREHOUSE_COUNT` | `9` | 셀메이트 기준 필터에 선택돼야 할 창고 수 |
| `SELLMATE_URL_KEY` | `sellmate` | 셀메이트 탭 주소에 포함된 글자 |
| `COLOR_MAP` | — | 한글/영문 색상명 통일표 (옵션 매칭용, 필요시 추가) |

## 문제 해결

- 실행 기록은 `재고동기화_로그.txt`에 남습니다.
- 검색칸이나 표를 찾지 못하면 `진단/` 폴더에 해당 화면 스크린샷과 HTML이 저장됩니다. 이 파일로 선택자를 수정하면 됩니다.
- `크롬에 연결하지 못했어요` → 크롬을 모두 닫고 `크롬_자동화모드.bat`로 다시 여세요.
- 옵션이 빨간 테두리(매칭 실패)로 나오면 셀메이트와 29CM의 색상 표기가 다른 경우가 많습니다. `COLOR_MAP`에 추가하세요.

## 참고

- 셀메이트·29커넥트 화면 구조가 바뀌면 선택자 수정이 필요할 수 있습니다.
- 로그인 정보는 코드에 저장하지 않으며, 별도 크롬 프로필(`%USERPROFILE%\chrome-29cm-auto`)에만 남습니다.
